# Assets

Every asset in the app is either drawn in code, generated by a script in this repository, or used
under an open license. Nothing is taken from another game.

## Graphics

All graphics are drawn in code with Jetpack Compose (Canvas, gradients, paths). There are no image
files apart from the launcher icon, which is a vector drawable made for this project.

| What | Where |
|---|---|
| Board, frame, stars, arrows | `app/src/main/java/com/example/ludoduel/ui/game/BoardSurface.kt` |
| Pawns (tokens) | `ui/game/TokenPainter.kt` |
| Dice | `ui/game/Die.kt` |
| Confetti, stars, sparkles | `ui/game/Effects.kt` |
| Trophy, confetti rain, buttons, background pattern | `ui/components/Showcase.kt`, `ui/theme/Theme.kt` |
| Icons (help, sound, settings) | `ui/components/Glyphs.kt` |
| Launcher icon | `app/src/main/res/drawable/ic_launcher_*.xml` |

## Font

| File | Font | Source | License |
|---|---|---|---|
| `app/src/main/res/font/baloo2.ttf` | Baloo 2 (variable weight 400–800) by Ek Type | Google Fonts, <https://github.com/google/fonts/tree/main/ofl/baloo2> (`Baloo2[wght].ttf`) | SIL Open Font License 1.1, see `licenses/OFL-Baloo2.txt` |

The OFL allows bundling the font in an app, including commercial apps, as long as the font file
itself is not sold on its own and the license travels with it.

## Sounds

All sounds are original. They are synthesized from sine tones, simple harmonics and filtered noise
by `tools/generate_sounds.py` (Python standard library only, fixed random seed, so the output is
reproducible). No recordings or third-party samples are used. They are released with the project
(you own them; treat them as CC0).

| File (`app/src/main/res/raw/`) | Used for | How it is made |
|---|---|---|
| `sfx_roll.wav` | Dice roll | Irregular filtered-noise knocks that slow down and fade, like a die in a cup |
| `sfx_hop.wav` | Each token hop | Short 1.1 kHz wooden tick |
| `sfx_capture.wav` | Capture ("bonk") | Falling pitch 520 → 150 Hz with a noise knock |
| `sfx_home.wav` | Token reaches home | Bell-like C6–E6–G6 arpeggio |
| `sfx_six.wav` | Rolling a six | Quick upward shimmer of high tones |
| `sfx_win.wav` | Winning | G4–C5–E5 then a C major chord, brassy harmonics |
| `sfx_lose.wav` | Losing | Two soft falling notes (C5, G4) |
| `sfx_click.wav` | Button press | Very short pop |
| `sfx_your_turn.wav` | Your turn | Two-note chime E5 → A5 |

To regenerate: `python3 tools/generate_sounds.py` from the project root.
